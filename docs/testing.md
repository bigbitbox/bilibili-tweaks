## 篡改猴加载测试

使用与用户一致的 Tampermonkey 5.5.0 扩展程序文件，在虚拟机独立 Chromium profile 中加载，开启 Allow User Scripts，先通过编辑器准备测试脚本，再从公开 GitHub 安装链接完成真实安装；没有复制扩展的私人存储。

解压加载的扩展在浏览器重启后可能触发脚本来源校验。`test/extension.mjs` 会从公开仓库重新安装当前脚本，再验证页面。没有关闭篡改猴的来源检查。

复现需先准备独立的已安装脚本的测试 profile。`SCRIPT_URL` 可指向某个提交的原始脚本，以避开 main 分支短时间内的 CDN 缓存；安装页版本必须与本地待验收版本一致。

```sh
TM_PATH=/path/to/tampermonkey \
TM_PROFILE=/path/to/test-profile \
VIDEO_URL=https://www.bilibili.com/video/BV1Wpb56RE63/ \
node test/extension.mjs
```

实测通过：GitHub 安装流程、实际 GM 存储跨页面刷新、推荐开关、长按恢复，以及真实页面中的弹幕、宽屏、网页全屏。普通页面的 `window.GM_getValue` 为 undefined，测试未注入 GM 替身；数据由篡改猴实际保存。宽屏后实际宽度为 1233px，`data-screen=wide`；网页全屏后原站标记为 `mode-webscreen`。1.1.0 新增按键也已实站验证：空格短按能暂停/播放，长按达到 2×，松手恢复 1.3×；1/2/3/4 的速度依次为 1/1.3/1.5/2；右方向键只快进，不改变倍速。没有捕获页面 JavaScript 异常。实站测试为可选联网测试，不放入 CI。

## 尚未覆盖

未登录验证不涵盖会员或付费场景。番剧、课堂、活动、旧版播放器没有逐一进行实站验证；`bwp-video` 目前只有属性兼容回归，没有真实软解码视频实测。全屏挂载通过浏览器回归验证。字幕内容依赖视频本身提供，没有验证所有字幕语言与剪贴板授权情况。其他第三方脚本同时运行时不保证无冲突，安装说明建议对 B 站只启用一套播放器增强。
